Theme and styling for webviews, popups, and UI elements in this project MUST be monochrome and minimal.
- Do NOT use vibrant colors, gradients, or flashy glow effects.
- Use flat buttons with neutral background/borders (shades of grey/black/white) and standard focus outlines.
- Maintain visual harmony with VS Code dark and light theme variables.
- Use Unicode characters (e.g., +, ✎, ×, ▤, 👤︎) or simple text labels for icons instead of custom SVG packages or external icon libraries whenever possible. Keep them strictly monochrome.
